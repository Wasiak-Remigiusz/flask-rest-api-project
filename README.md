## 📌 Summary

This project is an educational REST API built with **Flask**, using a **PostgreSQL** database and deployed via **Docker**. It allows users to create and manage **online stores and items**, and provides a live **Swagger UI** for API testing and documentation.

Main features include:

- Create and manage **stores**
- Add and modify **items** associated with stores
- Perform full CRUD operations on both
- Secure endpoints using **JWT authentication**
- Explore API via **Swagger UI**

---

## 🎯 Project Goal

The goal of this project is to provide a fully functional REST API for managing online stores and their items, built with scalable and widely-used technologies.

Key features and components include:

- REST API with Flask
- PostgreSQL + SQLAlchemy for database interaction
- User authentication
- Docker for containerization
- Swagger UI for testing and documentation
